# 🏭 Defect-Detacion

**AI-based defect detection system** that uses computer vision to automatically identify and classify product defects in manufacturing lines — reducing manual inspection time and catching defects the human eye misses.

## ✨ Features

- 📷 **Computer vision** — automatically detects defects from product images
- 🏷️ **Classification** — categorizes defects by type and severity
- 🏭 **Manufacturing-ready** — designed for production-line quality control
- ⚡ **Real-time** — built for inline inspection workflows

## 🎯 Use Cases

| Industry        | Example Defects Detected              |
| --------------- | ------------------------------------- |
| Automotive      | Scratches, dents, paint defects       |
| Electronics     | Solder defects, component misalignment |
| Textiles        | Weaving flaws, stains                 |
| Packaging       | Print defects, seal failures          |
